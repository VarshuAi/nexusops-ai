# Contributing to NexusOps AI

Thank you for your interest in contributing to **NexusOps AI**!

## Getting Started

1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/your-username/nexusops-ai.git
   cd nexusops-ai
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## Development Workflow

- Create a descriptive feature branch: `git checkout -b feat/custom-agent-support`
- Verify that the build succeeds without type errors before opening a PR:
  ```bash
  npm run build
  ```
- Commit your changes with conventional commit messages: `git commit -m "feat(agents): add custom agent export"`
- Push to your branch and submit a Pull Request!
